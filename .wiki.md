# Project Summary
The Drecar project aims to develop a modern website for Drecar, a car dealership in Afife, Portugal. This platform showcases vehicles for sale, provides contact information, and features an "About Us" section, all in Portuguese (Portugal). Built with React, JavaScript, and Tailwind CSS, the project focuses on delivering an engaging user experience for potential customers.

# Project Module Description
- **Homepage**: Displays featured cars and navigation.
- **About Us**: Provides information about the dealership.
- **Car Gallery**: Showcases available cars for sale.
- **Contact**: Contains contact details for inquiries.

# File Description Inventory
- **README.md**: Contains project information and setup instructions.

- **package.json**: Lists project dependencies and scripts for running the project.

- **public/data/example.json**: Sample JSON data for development.
- **src/App.jsx**: Updated root component of the React application, now includes Header, About, Contact, and CarGallery components.

- **vite.config.js**: Configuration for Vite, the build tool used in the project.

# Technology Stack
- **React**: JavaScript library for building user interfaces.
- **JavaScript**: Primary programming language for the application.
- **Tailwind CSS**: Utility-first CSS framework for styling.
- **Vite**: Build tool for modern web applications.

# Usage
1. Install dependencies:
   ```bash
   pnpm install
   ```
2. Run linting:
   ```bash
   pnpm run lint
   ```
3. Start the development server:
   ```bash
   pnpm run dev
   ```
