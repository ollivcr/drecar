# Project Summary
This project is a modern car dealership website designed to serve as a digital showcase for a car dealership. Built using React and Tailwind CSS, it features a responsive layout that allows users to browse a gallery of cars, learn about the dealership, and contact the business. The site is fully localized in Portuguese (Portugal) to cater to the target audience.

# Project Module Description
The website consists of several functional modules:
- **Homepage**: Displays a gallery of cars with filtering options.
- **About Us Page**: Provides information about the dealership's history and values.
- **Contact Page**: Includes a contact form for inquiries.
- **Header and Footer Components**: For navigation and additional information.

# Project Summary
The Drecar project is a modern car dealership website that serves as a digital platform for showcasing a variety of vehicles. Built with React and Tailwind CSS, it provides a responsive and user-friendly experience for browsing cars, learning about the dealership, and contacting the business. The site is fully localized in Portuguese (Portugal) and has been recently updated with a new logo, corrected social media links, and improved content.

# Project Module Description
The website consists of several functional modules:
- **Homepage**: Displays a gallery of cars with filtering options.
- **About Us Page**: Provides information about the dealership's history and values.
- **Contact Page**: Includes a contact form for inquiries.
- **Header and Footer Components**: For navigation and additional information.
